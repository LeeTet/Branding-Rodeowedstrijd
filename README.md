# Branding-Rodeowedstrijd
Branding kajak old-stuff: 
Dit is de het verslag van de NKB-Branding-Rodeowedstrijd in de periode van 1998 - 2001.
Deelnemende kajakkers showen gedurende een wave-performance hun kajakvaardigheden in de Noordzee-branding aan een jury.
De kajakkers worden beoordeeld op de uitvoering van horizontale (surfs, flat-spins etc.) en verticale rodeo-moves (loops, pirouettes, cartwheels etc.). Ook vaarstijl en de variëteit van acties tellen mee bij de beoordeling.
Deelnemers komen tegen elkaar uit in heats van 2-4 personen.
Om tot een evenwichtige heatindeling te komen worden de aanvangsheats ingedeeld volgens de ranking-lijst.
Het wedstrijdsysteem berust op het z.g.n. 'knock-out' principe: Telkens stromen de beste kajakkers van een heat door naar een volgende ronde.
Uiteindelijk resulteert dit in de finale-winnaar.
